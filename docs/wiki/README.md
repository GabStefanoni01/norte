# Wiki da Norte

> **Encontre seu norte.**  
> Documentação técnica e funcional da plataforma Norte.

A Norte é uma plataforma de orientação de carreira que busca ajudar jovens e pessoas em transição profissional a identificar caminhos possíveis, organizar objetivos e encontrar oportunidades de desenvolvimento.

## Estado da documentação

Esta Wiki descreve a estrutura identificada no repositório e separa configuração confirmada de possibilidades futuras. Como o produto evolui, confira sempre o código e os arquivos de configuração antes de tratar um comportamento como garantido.

## Contribuindo com a documentação

1. Faça as alterações em uma branch.
2. Prefira exemplos executáveis e comandos compatíveis com os scripts dos respectivos `package.json`.
3. Não inclua chaves, tokens, senhas ou dados pessoais reais.
4. Abra um Pull Request descrevendo o motivo e o impacto da alteração.
